# 귀뜸 에디토리얼 리뉴얼

## 적용 범위

- 종이색 배경, 먹색 본문, 벽돌색 강조 및 명조 제목.
- public/brand/gwiteem-wordmark-ko.png: 한글 대표 로고. 기존 영문 리소스는 보존.
- public/brand/editorial-coffee.png: 달력 아래 장식 이미지.
- 대표 질문은 기존 질문 목록 API의 필터 없는 조회에서 is_daily 항목을 사용한다. 목록의 검색/카테고리/정렬 변경과 독립적이며 목록에서 현재 대표 질문을 제외한다.
- 대표 질문 및 목록은 기존 상세 모달/투표 흐름에 연결한다.

## 추가 개발이 필요한 기능

- 날짜별 대표 질문 이력과 조회 API. 현재 첫 페이지에 is_daily가 없으면 대표 질문 준비 상태를 표시한다. 대표 질문 전용 API가 마련되면 이 조회를 교체해야 한다.
- 질문이 있는 날짜 집합과 월별 조회. 과거/미래 날짜 및 월 이동은 현재 비활성화한다. 가짜 날짜나 질문을 서비스에 노출하지 않는다.
- 과거 날짜 조회가 연결되면 선택 날짜 상태와 '오늘로 돌아가기' 버튼을 활성화한다.
- 현재 장식은 공통 커피 이미지이며 카테고리별 이미지 매핑은 추가 작업이다.

## 리소스 생성

내장 image_gen 도구로 생성. 로고 프롬프트: 시안 좌상단의 귀뜸 붓글씨를 보존하고 영문/장식을 제거한 투명 배경 로고. 일러스트 프롬프트: 책 두 권 위 커피와 받침, 섬세한 갈색 잉크 판화, 투명 배경, 글자 없음.
